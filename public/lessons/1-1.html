Definition

Key definition

Snowflake is a cloud data platform: a service on the internet where companies store very large amounts of data and ask questions about it quickly.

You will also hear it called a data warehouse or a data cloud. For this course they all mean the same thing: one big, managed place where a company keeps its data so that many people can ask questions of it at the same time.

Three words in that definition matter:

  • Cloud: it runs on the internet. The company installs nothing and owns no servers.
  • Store: it can hold billions of rows (every payment, trade or customer a company has ever had).
  • Ask questions: people ask using SQL, a simple language for questions about data. You will write some in a few minutes.

Think of it like a library in the sky

Picture a huge library floating above the clouds. You never build it, clean it or fix its lights; someone else does that. You bring your books and ask the librarians questions such as “How many red books do we have?” They run off, find the answer and come back in seconds. You pay only for the minutes the librarians spend working, and if you need an answer faster, you can call in more librarians.

In the libraryBooksIn Snowflake: your data, such as customers, payments and trades
In the libraryLibrariansIn Snowflake: the computers that find answers
In the libraryQuestionsIn Snowflake: the SQL queries you write

We will keep using this library in every lesson. Each new idea becomes one more part of it, which makes it much easier to remember.

Why companies moved to Snowflake

Before cloud platforms, a bank bought its own database servers and kept them in its own building. That is like every family building its own private library: expensive, slow to grow and always too small at the worst moment.

The old way (own servers)With Snowflake
Getting startedBuy hardware, install software, wait weeksSign up and start in minutes
Running out of spaceBuy and install more disksStorage grows automatically
Busy month-endEveryone’s reports slow down togetherEach team gets its own compute, so nobody waits
PayingPay for machines even when idle at nightPay for compute only while it runs, by the second (minimum one minute each time it starts)
MaintenanceA team patches, tunes and backs up serversSnowflake does it for you
Good to know

Snowflake itself runs on top of Amazon Web Services, Microsoft Azure or Google Cloud. The company picks one, but you use Snowflake exactly the same way on all three.

In practice: a bank

A global bank records millions of card payments, transfers and trades every day. All of it flows into Snowflake, and different teams ask their own questions of the same data:

TeamThe kind of question they ask
RiskHow much money could we lose if this market falls 10%?
FinanceWhat were total deposits in each region last month?
ComplianceWhich transfers above a limit must we report to the regulator?
FraudWhich cards were used in two countries within one hour?

Every one of these is a SQL query. Snowflake answers each in seconds, and because each team has its own compute, the Risk team’s huge month-end report does not slow down the Fraud team.

SQL in 2 minutes

A SQL question is built from a few keywords, always in this order. Read them like an instruction to the librarian.

KeywordWhat it meansTelling the librarian
SELECTWhich columns you want back“Bring me the city and the amount…”
FROMWhich table to look in“…from the transactions shelf…”
WHEREKeep only rows that match“…only deposits…”
GROUP BYPut rows into groups and total each“…one pile per city…”
ORDER BYSort the answer“…biggest pile first.”

Useful extras: SUM(amount) adds up, COUNT(*) counts rows, AS gives a column a friendly name, and text goes in 'single quotes'.

Lab: your first queries in Snowflake

Create a trial account and query real data

About 15 minFree 30-day trial

  1. Go to signup.snowflake.com and start a free trial. Choose the Enterprise edition, AWS as the cloud and the region closest to you. The trial is free for 30 days and comes with free credits.

  2. Open the activation link in the welcome email, choose a username and password, and sign in. The web interface you land in is called Snowsight.

  3. From the left menu open Projects → Worksheets (newer accounts call it Workspaces) and create a new SQL worksheet. A worksheet is where you type and run queries, just like the one on this page.

  4. Paste this and select Run. It asks Snowflake to introduce itself.

    SELECT CURRENT_ACCOUNT(), CURRENT_REGION(), CURRENT_VERSION(),
       CURRENT_USER(), CURRENT_ROLE(), CURRENT_WAREHOUSE();

    Expected: one row with your account, region, version, your username, your role (usually ACCOUNTADMIN in a trial) and the warehouse COMPUTE_WH.

  5. Now ask a question of real data. Every trial includes a sample database with 150,000 customers. This counts them by market segment:

    USE WAREHOUSE COMPUTE_WH;

SELECT c_mktsegment AS segment, COUNT(*) AS customers
FROM snowflake_sample_data.tpch_sf1.customer
GROUP BY c_mktsegment
ORDER BY customers DESC;

    Expected: 5 rows (AUTOMOBILE, BUILDING, FURNITURE, HOUSEHOLD, MACHINERY), each with roughly 30,000 customers. If you get “does not exist”, open Data → Databases and check that SNOWFLAKE_SAMPLE_DATA is listed.

  6. Look at the timing shown next to the results. Snowflake just grouped 150,000 rows in about a second, and you did not install or configure anything. That is the library in the sky at work.

Key takeaway

Remember

Snowflake is a library in the sky for data. You bring the data, it does the heavy lifting, and you pay only for the work done.

Glossary

Cloud
Computers you rent over the internet instead of owning.
Data platform
A system for storing data and answering questions about it. Snowflake is one.
Data warehouse
The traditional name for a large store of company data used for reports and analysis.
SQL
Structured Query Language: the standard language for asking questions of data.
Query
One question written in SQL.
Table
Data arranged in rows and columns, like a spreadsheet tab.
Snowsight
Snowflake’s web interface, where you write queries and see results.
Worksheet
A page in Snowsight where you type and run SQL.
