What is Cortex? (and CoCo vs Cortex)

Meet Snowflake’s AI layer: what lives inside Cortex, why running AI next to the data matters for a bank, and how Cortex differs from CoCo, the assistant that writes code for you.

Definition

Key definition

Snowflake Cortex is the AI layer built into Snowflake. It lets you use large language models (LLMs), search, question answering, agents and machine learning directly on the data you already keep in Snowflake, using SQL or simple APIs.

The important words are built into. You do not copy data to another AI service. The model comes to the data, not the other way round. Snowflake’s own overview says that, except where you choose otherwise, the AI models run inside Snowflake’s security and governance perimeter, and that Snowflake never uses your customer data to train models offered to other customers.

  • Cortex AI Functions (older name: AISQL or LLM functions): SQL functions such as AI_COMPLETE, AI_CLASSIFY, AI_SENTIMENT and AI_EXTRACT. One call per row, results come back as a column.
  • Cortex Search: a managed search service that finds text by meaning as well as by keywords. It powers chatbots over documents (RAG).
  • Cortex Analyst: turns a plain-English question into SQL using a semantic view, then runs it.
  • Cortex Agents: plan several steps and call Search, Analyst and other tools to answer a bigger question.
  • ML functions: ready-made forecasting, anomaly detection and classification on your tables.
  • Snowflake CoWork (formerly Snowflake Intelligence): the ready-made chat app where business users talk to agents.

Think of it like smart-reader librarians

Remember our library in the sky. The books are your data, the librarians are the warehouse and your ID badge (role) decides which shelves you may visit. Cortex adds a new team: smart-reader librarians. Hand them any book and they read it on the spot. They can tell you the mood of a letter, sort it into the right pile, pull out the amount of money mentioned, write a short summary or translate it. The book never leaves the building, and they are paid per word they read and write.

In the librarySmart-reader librariansIn Snowflake: Cortex AI Functions such as AI_SENTIMENT and AI_CLASSIFY
In the libraryA super indexIn Snowflake: Cortex Search, which finds passages by meaning, not only exact words
In the libraryThe head librarianIn Snowflake: a Cortex Agent who decides which helper should answer

There is also a different kind of helper in the building: a robot assistant who sits next to you and writes your request slips for you. That robot is CoCo. CoCo does not read the books for the bank’s customers. It helps you, the analyst, write the code. Keep these two jobs apart and the rest of the course is easy.

Why “AI inside the data” matters for a bank

Customer complaints and loan files are confidential. Sending them to an outside AI service means new contracts, new security reviews and copies of data in a second place. With Cortex the text stays under the same roles, masking policies and audit logs as any other table. A role that cannot see a column cannot send it to the model either. That is why bank risk teams approve Cortex much faster.

CoCo vs Cortex: the detailed comparison

Snowflake CoCo (its earlier name is Cortex Code, so the docs still use both) is an AI coding agent. It runs in Snowsight, as a desktop app and as a command-line tool. You type “write me a query that…” and it writes, explains or fixes code. Cortex is what your code calls to do AI on the data. The names sound alike, which causes most of the confusion on projects.

How they work together

The most common pattern on a project: CoCo writes the Cortex SQL. You ask CoCo for a query that classifies complaints; CoCo writes a statement that calls AI_CLASSIFY; you review it and run it; Cortex does the AI work on every row. One helps you build, the other does the work at scale.

Decision flow: which one do I need?

  1. Do I want help writing or fixing code? Use CoCo.
  2. Do I want AI to run on each row of a table (mood, topic, fields, translation)? Use a Cortex AI Function.
  3. Do I want to find passages in many documents or build a chatbot over them? Use Cortex Search.
  4. Do I want business users to ask numeric questions in English (“total deposits by city”)? Use Cortex Analyst.
  5. Do I need several of these in one answer? Use a Cortex Agent, and give users CoWork as the front door.
  6. Do I want to forecast or spot anomalies in numbers? Use the ML functions.
Common confusions

“Cortex Code is part of Cortex, so it reads my data for customers.” No: it is a coding assistant for you. “CoCo answers my business users.” No: CoWork and agents do that. “If CoCo wrote the query, the AI cost is CoCo’s.” No: CoCo bills for the chat; the query it wrote bills Cortex AI Credits every time it runs.

In practice: a bank

A retail bank receives about 40,000 complaints a month through the app, email, branches and the call centre. Here is how one team uses each tool in a single week:

Lab: find Cortex and CoCo in your trial

Spot both tools in Snowsight

About 15 minFree trial (Enterprise)

  1. Sign in to your Snowflake trial and open a SQL worksheet (Projects → Workspaces). Check which cross-region setting your account has; Cortex models and CoCo depend on it.

    USE ROLE ACCOUNTADMIN;
SHOW PARAMETERS LIKE 'CORTEX_ENABLED_CROSS_REGION' IN ACCOUNT;

    Expected: one row. New organisations created after 9 March 2026 default to ANY_REGION; older ones often show a same-cloud value such as AWS_US.

  2. Ask a Cortex AI Function a question. This is Cortex: it returns data.

    SELECT AI_SENTIMENT('The branch staff were kind but I waited 50 minutes.') AS mood;

    Expected: a small JSON object such as {"categories":[{"name":"overall","sentiment":"mixed"}]}.

  3. Open the CoCo panel in Snowsight (the assistant icon in Workspaces). Type: Write a SQL query that uses a Cortex function to score the sentiment of a text column called FEEDBACK in a table called REVIEWS. Read the code it proposes. Do not run it: the table does not exist yet.

    Expected: CoCo answers with SQL that calls AI_SENTIMENT. That is CoCo writing Cortex code. If you do not see the panel, your role may lack SNOWFLAKE.COPILOT_USER or a daily CoCo credit limit; skip this step on a client account.

  4. Write in your notes one sentence each: “Cortex is…” and “CoCo is…”. Use the comparison table above if you get stuck.

Key takeaway

Remember

Cortex is the AI that works on the bank’s data inside Snowflake. CoCo is the AI that helps you write code. CoCo often writes the SQL; Cortex does the AI work every time that SQL runs.

Glossary

Cortex
Snowflake’s AI layer: AI Functions, Search, Analyst, Agents, ML functions and CoWork.
LLM
Large language model: an AI trained on huge amounts of text that can read and write language.
AI Function
A SQL function that calls an AI model, such as AI_CLASSIFY. Formerly called AISQL or LLM functions.
CoCo
Snowflake’s AI coding agent (earlier name Cortex Code) in Snowsight, Desktop and CLI.
CoWork
Snowflake CoWork, formerly Snowflake Intelligence: the chat app where business users talk to agents.
Semantic view
A catalogue that explains tables, columns and metrics so Cortex Analyst writes correct SQL.
RAG
Retrieval-augmented generation: find the right passages first, then let the LLM answer using them.
AI Credit
The unit Snowflake uses to bill AI features, priced separately from warehouse credits.
