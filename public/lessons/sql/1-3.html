Sorting and LIMIT

Put the result in the order you want, then keep only the top few. Biggest balances, latest payments, oldest customers: all of them are ORDER BY plus LIMIT.

20 min Beginner Practice: 6 questions

By the end of this lesson you can

  • Sort a result with ORDER BY, smallest first or biggest first
  • Sort by more than one column
  • Keep only the first N rows with LIMIT, and skip rows with OFFSET
  • Say where blank values land in a sorted list

Definition

Key definition

ORDER BY sorts the rows of the result. LIMIT keeps only the first N rows of that sorted list. Together they answer every “top 5” and “latest” question.

Without ORDER BY, SQL gives rows in whatever order is fastest for the engine. That order can change from one run to the next. If the order matters to you, say so with ORDER BY. Every time.

ORDER BY runs last, after WHERE has removed rows. LIMIT runs after ORDER BY. So “the 3 biggest” means: filter, sort biggest first, keep 3.

Think of it like sorting the pile of cards

The librarian has copied the cards you asked for into a pile. ORDER BY balance DESC tells her: “arrange the pile so the biggest balance is on top”. LIMIT 3 tells her: “then hand me only the top three and put the rest away”. If two cards have the same balance, a second rule such as , acct_id tells her how to break the tie.

In the libraryArrange the pileIn SQL: ORDER BY, with ASC (small to big, the default) or DESC (big to small)
In the libraryHand me the top threeIn SQL: LIMIT 3
In the librarySkip the first three, then give me threeIn SQL: LIMIT 3 OFFSET 3

A card with a blank field cannot be placed by value. The librarian puts blanks at the end of the pile, unless you tell her otherwise. The Snowflake note below matters here.

How to write it, step by step

Step 1: the usual SELECT, FROM and (optional) WHERE. Step 2: ORDER BY and the column to sort on. Step 3: ASC or DESC. Step 4: LIMIT.

SELECT acct_id, balance
FROM accounts
WHERE acct_status = 'ACTIVE'
ORDER BY balance DESC
LIMIT 3;
KeywordWhat it meansTelling the librarian
ORDER BY colSort by that column, smallest first“Arrange the pile by balance, small to big.”
ASC / DESCAscending (default) or descending“…biggest on top, please.”
ORDER BY a, b DESCSort by a; inside equal a, sort by b biggest first“By type first, then biggest amount within each type.”
NULLS FIRST / NULLS LASTWhere blanks go“Blank cards at the bottom.”
LIMIT nKeep the first n rows“Only the top three.”
OFFSET mSkip m rows before counting“Skip three, then give me three.”

Text sorts A to Z. Dates sort oldest to newest, so ORDER BY txn_date DESC means newest first. You can also sort by a column that is not in the SELECT list, and by an alias you created with AS.

Common mistakes

Watch out

1. LIMIT 3 without ORDER BY gives three random rows, not the top three. Sort first, then limit.

2. ORDER BY balance, acct_id DESC applies DESC only to acct_id. Each column gets its own direction. Write balance DESC, acct_id DESC if you want both.

3. Clause order is fixed: WHERE, then ORDER BY, then LIMIT. LIMIT 3 ORDER BY balance is an error.

4. Sorting text that holds numbers gives '100' before '20'. Sort on a real NUMBER column.

5. Forgetting ties. Two accounts with the same balance can swap places between runs. Add a second key, such as acct_id, when the order must be stable.

On Snowflake

What is different on your project

Blanks sort differently. Snowflake treats NULL as the highest value: ORDER BY balance puts blanks last, but ORDER BY balance DESC puts blanks first. The worksheet engine (DuckDB) puts blanks last in both directions. When a column can be blank, write DESC NULLS LAST and both engines agree.

LIMIT and OFFSET work the same. Snowflake also accepts SELECT TOP 3 ... and FETCH FIRST 3 ROWS ONLY, which you will see in older scripts. They mean LIMIT 3.

Sort by position. ORDER BY 2 DESC sorts by the second column of the SELECT list. It works on both engines. It is handy in a hurry but easy to break when someone adds a column, so prefer names in saved code.

Practice

The same three bank tables. Row order does not count in grading, but LIMIT does: a “top 3” question is wrong if you return 4 rows. Column names do not matter.

Key takeaway

Remember

No ORDER BY, no promise about order. Sort first, then LIMIT. DESC for biggest or newest first. On Snowflake, blanks float to the top of a DESC sort unless you say NULLS LAST.

Glossary

ORDER BY
The clause that sorts the result rows.
ASC
Ascending: smallest, earliest or A first. The default.
DESC
Descending: biggest, latest or Z first.
Sort key
A column used for sorting. Several keys break ties in turn.
LIMIT
Keep only the first N rows of the sorted result.
OFFSET
Skip M rows before LIMIT starts counting. Used for paging.
NULLS LAST
An ORDER BY option that sends blank values to the end.
